### Подробное описание

```
Конспект любого видео на YouTube — за секунды.

Подключите почти любой сервис: Google AI Studio (Gemini), Groq, Cerebras, OpenRouter (модели «:free»), Zhipu GLM, GitHub Models, SambaNova, Together, Cloudflare Workers AI, NVIDIA NIM, Qwen, Mistral, DeepSeek, OpenAI, Anthropic и другие. Поддерживаются и локальные модели: Ollama, LM Studio, llama.cpp, vLLM, Jan — тогда данные не покидают компьютер.

Что вы получите:

• Краткая суть (TL;DR) и 5–14 ключевых пунктов
• Выводы, «что можно сделать», цитаты (вопросы для самопроверки — по желанию, в настройках)
• Разделы видео по смыслу или по главам — клик по заголовку перематывает видео
• Q&A: спросите о содержании — ответ с цитатами-источниками; без настроенного провайдера работает резервный поиск по транскрипту
• Экспорт в Markdown, текст или JSON (можно вместе с транскриптом)

Удобно:

• Панель прямо на странице видео — не нужно уходить с YouTube; светлая тема по умолчанию и переключатель светлая/тёмная
• Кнопка на странице, popup с быстрыми действиями, горячие клавиши (Alt+Shift+S / Alt+Shift+D), меню по правому клику на ссылке
• Кэш и история конспектов: повторное видео не тратит токены
• Готовые пресеты провайдеров с отметкой бесплатного тарифа, загрузка списка моделей и проверка связи в настройках
• Автопереключение на резервного провайдера при сбое

Приватность:

• Ключи API хранятся только в вашем браузере (можно — только до закрытия браузера)
• Локальный режим вообще не использует сеть
• В ИИ-режиме провайдеру уходит только текст субтитров и запрос на конспект
• Никакой аналитики, телеметрии и «домашних» серверов

Бесплатно и с открытым кодом (AGPL-3.0). Расширение не аффилировано с YouTube.
```

### Обоснование разрешений (permissions justification)

| Разрешение | Зачем |
| --- | --- |
| `storage`, `unlimitedStorage` | Хранить настройки, ключи, кэш конспектов и историю локально в браузере |
| `scripting`, `tabs` | Определять активную вкладку YouTube и добавлять/запускать панель на уже открытых страницах видео |
| `alarms` | Ежедневная очистка устаревших записей кэша |
| `contextMenus` | Пункт «Конспект OpenSummary для этого видео» по правому клику на ссылке и на странице видео |
| `downloads` | Экспорт конспекта в файл (Markdown / текст / JSON) |
| `host_permissions` для домена YouTube | Читать субтитры и метаданные видео на странице |
| `host_permissions` для API-хостов из списка | Отправлять запросы к выбранному пользователем ИИ-сервису |
| `optional_host_permissions` (`*://*/*`) | Пользователь может добавить свой endpoint (корпоративный шлюз, self-hosted модель). Доступ запрашивается отдельной кнопкой в настройках, только для нужного хоста |

**Single purpose statement:** расширение делает конспект видео YouTube через ИИ-провайдера, которого выбрал пользователь.

**Remote code:** не используется. Весь код — в пакете расширения; сеть применяется только для API-запросов к выбранному сервису и для загрузки субтитров YouTube.

### Ответы на вопросы про данные (Data usage)

* **Собираются ли персональные данные?** Нет.
* **Передаются ли данные третьим лицам?** Только по инициативе пользователя: текст субтитров уходит на endpoint выбранного ИИ-провайдера. Адрес хоста показан в настройках провайдера.
* **Продажа данных/реклама/трекинг?** Нет.
* **Шифрование:** запросы идут по HTTPS (кроме локальных моделей на `localhost`, где данные не покидают устройство).
* **Хранение:** настройки, ключи, кэш и история — в локальном хранилище браузера, удаляются кнопкой «Удалить все данные расширения».
